# 清醒醒來與安穩睡眠——原則與技巧
_整理日期：2026-08-24　|　針對：T1D、生酮＋間歇禁食、21:30–04:00 作息的個人化版本_

> 本文為衛教性質整理，不構成醫療建議；胰島素相關決策請與醫療團隊討論。

## 0. 證據力前提（AASM 官方立場）

美國睡眠醫學會（AASM）系統性回顧（Edinger et al. 2021, *J Clin Sleep Med*）結論：**「睡眠衛生清單」單獨使用時證據力不足**；真正有效的是 CBT-I 核心技術——**刺激控制、睡眠限制、放鬆訓練**（皆最高證據等級）。以下清單是地板，不是天花板；失眠持續時 CBT-I 是第一線治療。

- AASM 行為治療系統性回顧：https://pmc.ncbi.nlm.nih.gov/articles/PMC7853211/
- AASM 健康睡眠習慣：https://sleepeducation.org/healthy-sleep/healthy-sleep-habits/
- AASM/SRS 睡眠時數共識（成人 ≥7 小時）：https://www.aasm.org/resources/pdf/adultsleepdurationconsensus.pdf
- T1D 專屬 CBT-I 臨床試驗（進行中）：https://clinicaltrials.gov/study/NCT07091318

## 一、通用原則（AASM / CBT-I 核心）

| 原則 | 具體做法 |
|---|---|
| 規律性是王 | 固定睡醒時間（含週末，±1h 內）；成人 7h+ |
| 刺激控制 | 床只用來睡覺；20 分鐘睡不著就起床（暗光）做無聊的事，有睡意再回床 |
| 晨光校準 | 起床後 30–60 分鐘戶外自然光 10–30 分鐘——決定今晚褪黑激素幾點開工 |
| 夜間黑暗 | 全遮光、滅 LED；晚間暖光（redshift 2000K 已配置 ✓）；e-ink 螢幕優勢保持 |
| 溫度 | 臥室 18–20°C；核心體溫下降本身就是入睡信號 |
| 咖啡因/酒精 | 咖啡因過中午不碰（半衰期 5–6h）；酒精切碎後半夜睡眠 |
| 放鬆訓練 | 腹式呼吸、漸進式肌肉放鬆（AASM 最高等級；對壓力軸與血糖雙重有利） |
| 別賴床補眠 | 睡眠限制原理：縮短臥床換取睡眠效率；回籠覺是反模式 |

## 二、T1D 專屬層

1. **夜間血糖平穩是第一變數**——個人 186 夜資料：約半數夜晚抽樣到 <70；低血糖的腎上腺素反應是經典睡眠粉碎機
2. **睡前雙測**（就診值＋軌跡）比單點重要
3. **蛋白質尾部**：絞肉類晚餐升糖尾巴 3–6 小時——初始覆蓋寧早勿晚、寧足勿少
4. **篩檢睡眠呼吸中止症（OSA）**：T1D 族群盛行率高卻常被漏篩（Sleep-related disorders in T1DM, *Curr Diab Rep* 2020: https://pmc.ncbi.nlm.nih.gov/articles/PMC7023878/）
5. **限時進食（TRE）**：2026 首篇 T1D RCT 證實安全、HbA1c −0.5%（UIC/Varady, *Diabetes Care* 2026）
6. 睡眠與血糖雙向惡性循環的機制綜述：Reutrakul et al., *Sleep Med* 2016；AASM 立場：T1D 照護指引應納入睡眠評估

## 三、個人數據專屬教訓（186 夜分析，`BG_record/analysis/prebed_R_report.md`）

1. **就診血糖預測不了晨起狀態**（Spearman ρ≈0.02）——別用「今晚血糖好」預期「明天清爽」
2. **睡前 bolus 不改變清醒度**——R 夜回籠覺持平偏高；清醒度的槓桿在夜間曲線形狀
3. **「血糖正常卻狀況差」的早晨**是獨立現象——嫌犯：睡眠結構、電解質、皮質醇相位；CGM＋必要時睡眠檢查才能分辨
4. **回籠覺是反指標**——減少它的路徑是「夜間不塌陷」，不是「醒了再睡」

## 四、一日時間軸速查

```
04:00–06:00  醒 → 立即測BG＋進食（別回籠）→ 窗邊晨光 10–30 分鐘
上午          運動/活動（強化節律振幅）
12:00 之後    無咖啡因
17:00–19:00  晚餐（記錄蛋白質份量＝睡前針劑量的變數）
20:30 之後    redshift 暖光、e-ink、無藍光、無大餐
21:30–22:00  睡前雙測 → 按規則決定針 → 臥室全黑、18–20°C
夜間若醒      測BG → 處理 → 別滑手機 → 有睡意再回床（不開大燈）
```
